# Changelog

Все важные изменения проекта публикуются в этом файле.

## [Unreleased]

### Добавлено
- Нативная сборка под Windows: `windows/build.ps1` собирает единый
  `PotokBot.exe` (PyInstaller) вместе с `ffmpeg.exe` и `.env.example` в
  папку `dist/PotokBot/` — пользователю не нужны ни Python, ни Docker,
  ни WSL, бот запускается двойным кликом. При первом запуске `.env`
  создаётся автоматически из шаблона с подсказкой, что заполнить.
  Workflow `.github/workflows/build-windows.yml` собирает и публикует
  готовый архив автоматически в CI (артефакт на каждый пуш, вложение в
  GitHub Release на тег `v*`).
- Кнопка «✏️ Изменить описание» на превью поста: администратор может
  вручную задать новый заголовок/описание вместо извлечённого из видео.
  После отправки нового текста превью поста обновляется на месте (без
  спама новыми сообщениями).

## [1.1.0]

### Изменено
- Бот переписан с `aiogram 3.x` (async/aiohttp) на `pyTelegramBotAPI`
  (`telebot`, синхронный, поверх `requests`). Причина: на одном из
  деплоев `aiogram`/`aiohttp` не мог установить соединение с
  `api.telegram.org` (таймаут на этапе TCP-коннекта при каждом
  перезапуске), тогда как другой бот на той же машине работал без
  проблем — вероятно, из-за поведения `aiohttp` при обходе IPv4/IPv6
  (Happy Eyeballs) в сломанной сети контейнера. `requests`/`urllib3`
  устанавливают соединение иначе и не подвержены этой проблеме.
- FSM на основе `aiogram` заменена на простое состояние в памяти
  (словарь на процесс, под `threading.Lock`), так как `telebot` не
  предоставляет встроенный FSM-модуль.
- Параллелизм обработки сообщений обеспечивается пулом потоков
  `telebot` (`threaded=True`) вместо `asyncio`.

### Исправлено
- Callback-хендлеры публикации/отмены поста теперь проверяют `ADMIN_ID`
  (ранее любой пользователь, видевший сообщение с кнопками, мог
  инициировать публикацию в канал).
- Превью видео скачивается ботом самостоятельно (`download_thumbnail`) и
  отправляется файлом, а не прямой ссылкой — устраняет сбои превью для
  источников с защитой от хотлинкинга (VK, Instagram).
- При получении новой ссылки на видео клавиатура предыдущего
  незавершённого превью отключается, чтобы исключить публикацию
  устаревших данных.
- Интеграционный тест `parse_video_url` больше не проходит "тихо" без
  проверок при недоступности сети — явно помечается как `skipped`.

### Добавлено
- Команда `/start` с приветствием для администраторов.
- `.dockerignore`, исключающий `.env`, `.git` и служебные файлы из
  Docker-образа (ранее секреты могли попасть в собранный образ).
- Тесты для `download_thumbnail`.

## [1.0.0] - 2023-11-20

### Добавлено
- Инициализация проекта Telegram-бота на `aiogram 3.x`.
- Извлечение данных видео (заголовок, обложка) с использованием `yt-dlp`.
- Фильтрация сообщений только от авторизованных администраторов (`ADMIN_ID`).
- Предпросмотр поста перед публикацией с интерактивными кнопками.
- Автоматическая публикация в Telegram-канал (`CHANNEL_ID`).
- Поддержка переменных окружения через `pydantic-settings`.
- Dockerfile с установленным `ffmpeg` и `docker-compose.yml`.
- CI/CD пайплайн в GitHub Actions (`tests.yml`) с `flake8` и `pytest`.
- Модульные и интеграционные тесты для парсера.
