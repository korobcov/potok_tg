Telegram Video Poster Bot - Windows

Быстрый старт
-------------
1. Дважды кликните PotokBot.exe.
   При самом первом запуске он сам создаст рядом файл .env и попросит
   заполнить его - откройте .env блокнотом и укажите:

     BOT_TOKEN=...   - токен бота от @BotFather
     ADMIN_ID=...    - ваш числовой Telegram ID (можно несколько через запятую)
     CHANNEL_ID=...  - ID канала, куда бот будет публиковать посты

2. Сохраните .env и снова дважды кликните PotokBot.exe.
   Появится окно с логами - значит бот запущен и опрашивает Telegram.
   Не закрывайте это окно, пока бот должен работать.

Все зависимости (Python, библиотеки, ffmpeg) уже внутри этой папки -
ничего дополнительно устанавливать не нужно.

Подпись к посту (по желанию)
-----------------------------
Хотите, чтобы бот сам добавлял в конец каждого поста ссылки на другие
ваши каналы, на трансляции и т.п.? Скопируйте post_footer.example.txt
в post_footer.txt (в этой же папке) и отредактируйте текст блокнотом -
он будет автоматически добавляться в конец каждого поста.

Поддерживается разметка Telegram (HTML): <b>жирный</b>, <i>курсив</i>,
<u>подчёркнутый</u>, <s>зачёркнутый</s>, <a href="...">ссылка</a>,
<tg-spoiler>спойлер</tg-spoiler>, <blockquote>цитата</blockquote>.
Если файла post_footer.txt нет - подпись просто не добавляется, посты
работают как раньше. Изменения в post_footer.txt подхватываются сразу,
без перезапуска бота.

Автозапуск при загрузке Windows (по желанию)
---------------------------------------------
Создайте ярлык на PotokBot.exe и положите его в папку автозагрузки:
Win+R -> shell:startup -> вставьте туда ярлык.

Проблемы
--------
- Окно сразу закрывается / ошибка про BOT_TOKEN - проверьте .env
  (откройте его блокнотом, без лишних пробелов и кавычек).
- "Unauthorized" в логах - неверный BOT_TOKEN.
- Бот не отвечает на команды - проверьте ADMIN_ID (его можно узнать
  через @userinfobot в Telegram).
- Не публикуется пост - бот должен быть администратором канала,
  а CHANNEL_ID должен соответствовать этому каналу.
- Если Telegram заблокирован у вашего провайдера, укажите в .env
  строку PROXY_URL=http://user:pass@host:port и перезапустите бота.
