# Architecture & Rules (`ai.md`)

## Архитектура проекта
Проект построена по принципам модульности и чистого кода.

### Структура каталогов
- `app/config/settings.py`: Конфигурация приложения на основе `pydantic-settings`.
- `app/services/parser.py`: Сервисный слой для взаимодействия с внешними библиотеками (парсинг видео через `yt-dlp`).
- `app/handlers/admin.py`: Хэндлеры бота, фильтрация по администраторам, обработка команд, генерация предпросмотра и отправка постов.
- `app/main.py`: Точка входа для запуска бота и диспетчера.
- `tests/`: Модульные и интеграционные тесты для проверки функционала.

## Правила разработки и конвенции
1. **Асинхронность**: Тяжелые/блокирующие операции (такие как вызовы `yt-dlp`) ОБЯЗАТЕЛЬНО выполняются в отдельном потоке с использованием `asyncio.to_thread`.
2. **Безопасность и Валидация**: Доступ к функционалу бота ограничен фильтром по `ADMIN_ID`.
3. **Форматирование кода**: Весь код должен соответствовать стандарту PEP 8 и проходить проверку `flake8`.
4. **Тестирование**: Все новые сервисы должны покрываться тестами `pytest`.
